# src/ — the build pipeline

Three steps, in order. See `../REBUILD.md` for why any of it is the way it is.

```bash
python fetch.py           # ~155 MB of CSVs into raw/; skips what is already there
python build_payload.py   # ~3 min, ~1 GB RAM -> payload.json
python inject.py          # splice into template.html -> ../index.html
```

| file | what it is |
|---|---|
| `fetch.py` | downloads the four NYPL menu CSVs from the Internet Archive item |
| `build_payload.py` | the whole analysis: usable-page filter, Bradley–Terry fit, the three rigidity tests, era shifts, oyster beds, prices, ghost cards |
| `card_keys.txt` | the 194 dishes printed on the reconstructed card, picked by hand off the fitted order. Membership only — the order is always the fit's |
| `template.html` | the page, Artifact-shaped, with a `__DATA__` marker |
| `inject.py` | splices the payload, then runs `wrap_for_pages.py` and `add_catalog_link.py` |
| `raw/`, `payload.json`, `order_dump.txt` | gitignored; regenerated by the above |

Useful while working:

```bash
python build_payload.py --dump-order    # writes order_dump.txt, all 1,276 fitted dishes
```

`build_payload.py` asserts that Blue Points come out above Coffee on 457 of 457 shared pages. That
assert is load-bearing: it catches the pair table being indexed the wrong way round, which is
otherwise silent and reverses individual verdicts on the page.
